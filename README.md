# Kırık Leblebi Oyun Merkezi

BASMA! ve ZIPLA! tarayıcı oyunlarını aynı GitHub Pages sitesinden oynatan, kurulum gerektirmeyen statik site.

## Dosyalar

- `index.html`: Oyun seçme ana sayfası
- `basma.html`: BASMA! v1.7 oyunu
- `zipla.html`: ZIPLA! v0.9 oyunu

## GitHub Pages

Bu dosyaları deponun ana dizinine yükleyin. Settings → Pages → Deploy from a branch → main / (root) ayarıyla site açılır.

Ana sayfa: `https://kirikleblebi.github.io/basma/`
BASMA!: `https://kirikleblebi.github.io/basma/basma.html`
ZIPLA!: `https://kirikleblebi.github.io/basma/zipla.html`

Oyunların puan ve rekor kayıtları tarayıcının yerel depolama alanında tutulur; cihazlar arasında senkronize edilmez.
